# Life is Max Bet — Brand site

GitHub Pagesで公開するブランド紹介サイトです。BASEショップ完成前のため、現時点では商品販売・決済は行いません。

## Preview locally

Open `index.html` in a browser, or run a local static server from this folder.

## Publish

The `main` branch workflow in `.github/workflows/pages.yml` deploys the repository root to GitHub Pages. The repository must have Pages enabled for GitHub Actions.

## Before launch

- Replace the Instagram placeholder with the official profile URL.
- Add approved product and campaign photos under `assets/` and update the page.
- Confirm the brand name and copy.
- Link to the BASE shop after it is created and configured.
- Keep purchase terms and legal disclosures consistent with the actual seller and BASE settings.
